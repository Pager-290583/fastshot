# Fastshot

Fastshot — инструмент для скриншотов на Rust, повторяющий рабочий процесс и интерфейс
[Flameshot](https://flameshot.org): выделяете область, рисуете аннотации инструментами
вокруг выделения и копируете результат в буфер обмена, сохраняете, закрепляете на экране
или загружаете.

Проверено на Fedora 45, GNOME 51 под Wayland (с дробным масштабированием 1.67). На X11 тоже
работает.

## Установка

### Flatpak (рекомендуется)

Готовый пакет собирается GitHub Actions на каждый коммит в `main`. Скачайте
`Fastshot-x86_64.flatpak` со страницы
[Releases → Continuous build](https://github.com/Pager-290583/fastshot/releases/tag/continuous)
и установите:

```sh
flatpak install --user Fastshot-x86_64.flatpak   # рантайм подтянется с Flathub
```

После установки Fastshot появится в меню приложений. Запуск из меню оставляет иконку
в трее (в GNOME нужно расширение AppIndicator). Повторный запуск, пока трей работает,
сразу делает снимок. Клавишу Print трей регистрирует через портал Global Shortcuts:
при первом запуске GNOME попросит её подтвердить. Из терминала:
`flatpak run io.github.Pager_290583.Fastshot gui`.

При первом снимке GNOME один раз спросит разрешение на скриншоты для Fastshot.

Локальная сборка пакета:

```sh
flatpak install --user flathub org.flatpak.Builder
flatpak run org.flatpak.Builder --user --install --force-clean \
    --install-deps-from=flathub build flatpak/io.github.Pager_290583.Fastshot.yml
```

После изменения зависимостей (`Cargo.lock`) пересоздайте список офлайн-исходников:
`python3 flatpak/cargo-sources.py Cargo.lock > flatpak/cargo-sources.json`.
CI проверяет, что файл актуален.

Релизы: каждый push в `main` обновляет pre-release `continuous`, тег `vX.Y.Z` создаёт
обычный релиз.

### Без Flatpak

```sh
./install.sh               # сборка release и установка в ~/.local (bin, .desktop, иконка)
./install.sh --bind-print  # то же самое + привязка клавиши Print к `fastshot gui` в GNOME
```

Нужен Rust (`rustup`). Системные `-devel` пакеты не нужны: Wayland, X11 и EGL подгружаются
динамически. Для буфера обмена под Wayland нужен `wl-copy` (пакет `wl-clipboard`; во
Flatpak он уже внутри).

## Использование

| Команда | Что делает |
|---|---|
| `fastshot` / `fastshot tray` | иконка в трее (в GNOME нужно расширение AppIndicator) |
| `fastshot gui` | интерактивный захват: выделение и редактирование |
| `fastshot full` | весь рабочий стол |
| `fastshot screen [-n N]` | один монитор |
| `fastshot launcher` | окно лаунчера (режим, задержка, действия после захвата) |
| `fastshot config` | окно настроек; с флагами меняет настройки без окна |
| `fastshot pin FILE` | закрепить изображение поверх всех окон |
| `fastshot history` | история загрузок на Imgur |
| `fastshot install-shortcut [--key Print]` | глобальная клавиша в GNOME |

Флаги, общие с Flameshot: `-p/--path`, `-c/--clipboard`, `-d/--delay <мс>`, `-r/--raw`
(PNG в stdout), `-u/--upload`, а для `gui` ещё `-g/--print-geometry`, `--pin`,
`-s/--accept-on-select`, `--region WxH+X+Y`, `--last-region`.

```sh
fastshot gui                     # выделить → Enter → картинка в буфере обмена
fastshot gui -c -p ~/Pictures    # в буфер обмена и в файл
fastshot gui -r > shot.png       # PNG в stdout
fastshot full -c -d 2000         # весь экран через 2 с в буфер обмена
fastshot config --maincolor '#2a7fff' --showhelp false
```

## Экран захвата

Инструменты (буква — горячая клавиша):

| | Инструмент | | Инструмент |
|---|---|---|---|
| **P** | Карандаш | **M** | Маркер (полупрозрачный) |
| **D** | Линия | **T** | Текст (жирный, курсив, подчёркнутый, зачёркнутый, выравнивание) |
| **A** | Стрелка | **B** | Пикселизация |
| **S** | Прямоугольник-контур | **N** | Счётчик: нумерованный кружок, при протягивании с указателем |
| **R** | Залитый прямоугольник (толщина задаёт радиус скругления) | **I** | Инверсия цветов |
| **C** | Эллипс | | |

Действия: **Enter** — принять (по умолчанию копирует в буфер обмена), **Ctrl+C** — копировать,
**Ctrl+S** — сохранить, **Ctrl+P** — закрепить, **Ctrl+O** — открыть в приложении,
**Ctrl+U** — загрузить на Imgur, **Ctrl+Z / Ctrl+Shift+Z** — отменить/повторить,
**Esc / Ctrl+Q** — выход, **Ctrl+A** — выделить весь экран, **Ctrl+M** — режим перемещения.

Мышь и клавиатура:

- **колесо** меняет толщину или размер шрифта, рядом с курсором видно новое значение;
- **правая кнопка** открывает цветовое колесо: отпустите кнопку на нужном цвете;
- **Space** открывает боковую панель: палитра, толщина, стиль текста, «Grab Color» (пипетка),
  отмена и повтор;
- **Shift** при рисовании выравнивает линии по 45° и делает квадраты и круги;
- **стрелки** сдвигают выделение на 1 px, **Shift+стрелки** меняют его размер;
- без активного инструмента клик по нарисованному объекту выделяет его: объект можно
  перетащить, удалить клавишей **Delete**, поменять ему цвет или толщину. Клик инструментом
  «Текст» по существующему тексту открывает его для редактирования;
- выделение меняется за ручки или края, а без инструмента его можно перетаскивать целиком.

## Закреплённое изображение (pin)

Окно без рамки поверх остальных. Перетаскивание двигает окно, колесо масштабирует,
**Ctrl+колесо** меняет прозрачность, двойной клик или **Esc** закрывают. В контекстном меню:
копировать, сохранить, повернуть, прозрачность, сброс, закрыть.

## Настройки

Файл `~/.config/fastshot/fastshot.toml`, редактируется в `fastshot config`:

- цвета интерфейса, прозрачность затемнения, набор и размер кнопок, палитра цветового колеса;
- шаблон имени файла в формате strftime (`%F_%H-%M`), папка сохранения, сохранение без диалога,
  формат по умолчанию (png/jpg/webp/bmp), качество JPEG;
- уведомления, трей, автозапуск, копирование по двойному клику, сохранение после копирования,
  копирование пути после сохранения, JPG для буфера обмена;
- Imgur Client ID (зарегистрируйте приложение на https://api.imgur.com/oauth2/addclient).

Последние цвет, толщины и стиль текста запоминаются между запусками.

## Устройство

| Модуль | Назначение |
|---|---|
| `capture.rs` | захват: портал `org.freedesktop.portal.Screenshot` (Wayland) и `XGetImage` (X11), мониторы через RandR |
| `overlay.rs` | экран захвата на egui: выделение, ручки, кнопки, панель, колесо, текстовый редактор, undo/redo |
| `annotation.rs` | модель объектов: геометрия, hit-test, перемещение |
| `render.rs` | растеризация через tiny-skia и ab_glyph. Один и тот же код рисует превью и итоговую картинку, на экране то же, что попадёт в буфер. Экран обновляется только в изменённой области |
| `export.rs` | буфер обмена (`wl-copy` или X11-сервер `fastshot clipboard-serve`), файлы, уведомления, «открыть в», Imgur, история |
| `pin.rs`, `windows.rs`, `upload.rs`, `tray.rs` | окна pin, лаунчер, настройки, история, «о программе», загрузка, трей |

Каждое окно запускается отдельным процессом, как дочерние окна у Flameshot. Захват ничего
не ждёт от фонового демона.

### Тесты

```sh
cargo test                                   # рендер всех инструментов
FASTSHOT_TEST_OUT=/tmp/tools.png cargo test  # то же самое + PNG для просмотра
FASTSHOT_SCRIPT=script.txt fastshot gui -r > out.png   # сценарий ввода, формат в src/script.rs
```

## Ограничения Wayland

- Глобальные клавиши приложению недоступны. Используйте `fastshot install-shortcut`: он
  создаёт пользовательскую привязку GNOME и переносит стандартный скриншотер на `Shift+Super+Print`.
- Позицию окна pin задаёт композитор. На X11 окно открывается на месте выделения.
- При нескольких мониторах `fastshot gui` работает на основном мониторе (`fastshot full` и
  `fastshot screen -n N` снимают любой).
